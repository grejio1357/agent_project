# MCP 기반 AI 검색 시스템

## 프로젝트 개요

본 프로젝트는 농업 데이터를 대상으로 한 **하이브리드 AI 검색 에이전트 시스템**입니다.  
정형 데이터(SQL)와 비정형 지식(RAG)을 동시에 지원하여, 사용자의 질의 유형에 따라
가장 적합한 검색 방식을 선택하고 통합된 답변을 제공합니다.


## 문제 정의 및 기획 배경

농업 데이터는 생산량, 면적, 수확량 등과 같은 **수치 중심의 정형 데이터**가 대부분이기 때문에  
특정 조건이나 기간에 대한 값을 정확히 조회하기 어렵습니다.

반면, 농업 분야에 익숙하지 않은 사용자들은  
이론적 배경이나 설명 중심의 **비정형 지식 정보**를 함께 필요로 하는 경우가 많습니다.

이 프로젝트는 이러한 문제를 해결하기 위해  
**SQL 기반 정형 데이터 검색과 RAG 기반 비정형 지식 검색을 하나의 시스템으로 통합**하는 것을 목표로 기획되었습니다.


## 주요 기능

- 키워드 패턴 기반 **질의 의도 분류**  
  (SQL / RAG / Hybrid 검색 여부 판단)
- **이중 에이전트 구조**를 활용한 하이브리드 검색
  - SQL 기반 정형 데이터 조회
  - RAG 기반 비정형 지식 검색
- LangGraph 기반 워크플로우를 통한 에이전트 실행 및 상태 관리
- 여러 에이전트의 검색 결과를 통합한 **단일 응답 생성**
- 확장 가능한 **모듈형 아키텍처**

## 검색 전략 (Retrieval Strategy)

본 시스템은 **정형 데이터와 비정형 데이터의 검색 경로를 분리**하여 설계되었습니다.

### 1. 비정형 지식 검색 (RAG)

RAG 에이전트는 3단계 파이프라인으로 구성됩니다.

1. **OpenSearch**  
   - 키워드 기반 1차 필터링을 통해 검색 범위를 빠르게 축소
2. **FAISS**  
   - 축소된 문서 집합을 대상으로 벡터 기반 의미 검색 수행
3. **LLM 기반 재정렬(Reranker)**  
   - FAISS 결과 중 가장 관련성 높은 문서를 선별하여 최종 답변 생성에 사용


### 2. 정형 데이터 검색 (SQL)

SQL 에이전트는 다음과 같은 파이프라인을 따릅니다.

1. **질의 의도 분류**  
   - 정형 데이터 검색이 필요한 질의인지 판단
2. **LLM 기반 Text-to-SQL 변환**  
   - 사용자 질의를 SQL 쿼리로 변환
3. **PostgreSQL 실행**  
   - Docker 환경에서 SQL 실행 후 실제 수치 데이터 조회

이를 통해 자연어 질의가 **정확한 SQL로 변환되어 신뢰성 있는 결과**를 반환할 수 있도록 설계되었습니다.


## 개발 과정

프로젝트 초기 단계에서는 전체 **폴더 구조 설계 및 에이전트별 역할 정의**부터 진행하였습니다.

첫 번째 단계로 SQL 파이프라인을 구현하였으며,  
PostgreSQL을 Docker 컨테이너로 구성하고  
한국 공식 농업 통계 데이터를 테이블 형태로 적재하였습니다.  
이후 SQL 에이전트를 구현하여 정형 데이터 검색의 정확성을 검증하였습니다.

다음으로 FAISS를 활용한 RAG 파이프라인을 구축하였고,  
단독 테스트 이후 OpenSearch를 추가하여 키워드 기반 1차 검색 단계를 통합하였습니다.

마지막으로 LangGraph를 사용하여  
각 에이전트를 하나의 워크플로우로 오케스트레이션하였으며,  
FastAPI 기반 백엔드와 React 프론트엔드를 통해  
통합 검색 인터페이스를 완성하였습니다.


## 문제 해결 및 개선 사항

### 1. Text-to-SQL 정확도 문제

다중 조건 비교가 필요한 질의에서  
LLM이 단일 조건만 반영하는 SQL을 생성하는 문제가 발생하였습니다.

이를 해결하기 위해 프롬프트에  
- 비교 조건 명시  
- 출력 형식 제약  
을 추가하여 SQL 생성 정확도를 크게 개선하였습니다.


### 2. Docker 환경 안정성 문제

컨테이너 실행 중 비정상 종료 문제가 발생하였으며,  
기존 컨테이너 및 볼륨을 제거한 후  
환경을 초기화하여 재구성함으로써 문제를 해결하였습니다.

## 실행 방법

### 사전 준비
- Docker
- Python 3.10 이상
- Node.js 18 이상

### 1. 필수 서비스 실행
PostgreSQL 및 OpenSearch 컨테이너 실행:

bash
docker-compose up -d postgres opensearch

### 2. 벡엔드 서버 실행
cd backend
python -m venv venv
venv/Scripts/activate
pip install -r requirements.txt
uvicorn main:app --reload

### 2. 프론트엔드 서버 실행
cd frontend
npm install
npm start
